# relro.site

Jekyll сайт за RELRO, готов за GitHub Pages.

## Структура

| Файл | Какво съдържа |
| --- | --- |
| `_config.yml` | Имейл, локация, домейн, дата за брояча, `noindex` |
| `_data/capabilities.yml` | Редовете на матрицата: услуга, описание, регулации, етапи, какво получава клиентът |
| `_data/standards.yml` | Колоните: регулации и стандарти, с кратко обяснение за филтъра |
| `_data/engagements.yml` | „Ways to work with us“ |
| `_data/record.yml` | „Done before“ |
| `index.html` | Началната страница (Liquid шаблон) |
| `_layouts/default.html` | `<head>`, фоновата анимация, скриптовете |
| `assets/css/site.css` | Стилове |
| `assets/js/field.js` | Фоновата анимация (хеш дървото) |
| `assets/js/site.js` | Матрицата (отваряне на редове, филтър) и брояча |
| `CNAME` | Домейнът: `relro.site` |

Текстовете се сменят в `_data/*.yml`, без да се пипа HTML.
Нова регулация: добави я в `standards.yml` и сложи ключа ѝ в `standards:` на услугите в `capabilities.yml`.

Линк с готов филтър: `https://relro.site/?std=cra` (ключовете са в `standards.yml`).

## Качване в GitHub

1. Създай ново хранилище в GitHub, например `relro-site`.
2. Качи съдържанието на тази папка в клона `main`, в корена на хранилището.
3. В хранилището: **Settings → Pages**.
   - **Source:** Deploy from a branch
   - **Branch:** `main`, папка `/ (root)`
4. Изчакай 1–2 минути. Сайтът се появява на `https://<потребител>.github.io/relro-site/`.
   Докато домейнът не е насочен, тук стиловете може да не се зареждат правилно. Това се оправя, щом домейнът заработи.

## Насочване на домейна relro.site

При регистратора на домейна добави тези DNS записи:

| Тип | Име | Стойност |
| --- | --- | --- |
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| AAAA | `@` | `2606:50c0:8000::153` |
| AAAA | `@` | `2606:50c0:8001::153` |
| AAAA | `@` | `2606:50c0:8002::153` |
| AAAA | `@` | `2606:50c0:8003::153` |
| CNAME | `www` | `<потребител>.github.io` |

След това:

1. **Settings → Pages → Custom domain:** `relro.site` (файлът `CNAME` вече го съдържа).
2. Изчакай DNS проверката да мине. Може да отнеме от няколко минути до няколко часа.
3. Включи **Enforce HTTPS**.
4. Препоръчително: потвърди домейна в профила си (**GitHub → Settings → Pages → Verified domains**).
   Така никой друг не може да го закачи за свое хранилище.

## Преди публикуване

- `_config.yml` → `noindex: false` позволява на търсачките да индексират сайта. Сложи `true`, ако още не е готов.
- `_data/record.yml`: провери, че договорите ти позволяват да споменаваш тези проекти.
- `_data/standards.yml`: съпоставката с регулациите е ориентировъчна. Прегледай я.

## Локален преглед (по желание)

Изисква Ruby:

```bash
bundle install
bundle exec jekyll serve
```

После отвори `http://localhost:4000`.
